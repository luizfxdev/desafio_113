Decifrando o Código Secreto da Floresta Encantada 🌲🔍


Bem-vindo, aventureiro, à Floresta Encantada, onde os segredos estão escondidos em códigos misteriosos. Para cruzar a floresta, deve-se decifrar o enigma da Árvore Anciã, que guarda um código numérico secreto.

O código é composto por uma sequência de números inteiros, mas cada número deve ser multiplicado por seu índice na lista (começando do índice 1) e então somado para revelar o Número Mágico da floresta.

✨ Desafio: Escreva um código que receba uma lista de números inteiros e retorne o Número Mágico.

Entrada: Uma lista de números inteiros.
Saída: Um único número inteiro, que é o resultado da operação revelada pelo código.

Exemplo:

Entrada: [2, 3, 5, 7]
Saída esperada: 50

// Cálculo: (2*1) + (3*2) + (5*3) + (7*4) = 50
